# OitoGameLab

Ein Labor für kleine Browser-Spiele, prozedurale Welten und ungewöhnliche Spielmechaniken. Der Schwerpunkt liegt auf Android im Hochformat mit Touch-Steuerung.

| Projekt | Spielen | Dokumentation |
| --- | --- | --- |
| OitoEngine | [Engine-Demo](https://oitow.github.io/OitoGameLab/engine/) | [Entwicklungsstart](engine/README.md) · [Roadmap](engine/ROADMAP.md) |
| Island Explorer | [Prototyp](https://oitow.github.io/OitoGameLab/prototypes/island-explorer/) | [Quellordner](prototypes/island-explorer/) |

Die Engine liegt in `engine/`. Eigenständige Experimente liegen in `prototypes/`. Für Beiträge und KI-Agenten gilt [AGENTS.md](AGENTS.md).

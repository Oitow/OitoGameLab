# OitoGameLab 🎮

Ein experimentelles Game-Development-Labor für kleine, spielbare Prototypen, ungewöhnliche Spielmechaniken und prozedurale Welten.

## Ziele

- Neue Spielideen schnell als spielbare Proofs of Concept (PoCs) testen.
- Mobile-first entwickeln: Android, Touch-Steuerung und Hochformat (9:16), wo sinnvoll.
- Einfache Prototypen bevorzugt mit HTML, CSS und JavaScript umsetzen.
- Für 3D-Experimente bei Bedarf Three.js einsetzen.
- Projekte übersichtlich halten und schrittweise verbessern.

## Projektstruktur

Jeder Prototyp bekommt später einen eigenen Ordner, zum Beispiel:

```text
OitoGameLab/
├── README.md
└── prototypes/
    └── beispiel-projekt/
        └── index.html
```

Die Ordner werden erst angelegt, wenn ein entsprechendes Projekt entsteht.

## Entwicklungsablauf

1. Idee und Kernmechanik festlegen.
2. Einen kleinen, direkt spielbaren Prototyp entwickeln.
3. Auf Android und Desktop testen.
4. Fehler beheben und Spielgefühl verbessern.
5. Änderungen mit nachvollziehbaren Git-Commits sichern.
